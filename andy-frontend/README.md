# Andy Homecare Connect – Frontend

React + Vite frontend for Andy Homecare Connect, Bungoma Kenya.

## Setup

```bash
npm install
npm run dev       # local development at http://localhost:3000
npm run build     # produces dist/ folder ready for deployment
```

## Deploy to Netlify

1. Run `npm run build`
2. Drag the `dist/` folder to netlify.com/drop
3. Done — instant live URL

## Connect to Backend

Edit line 4 of `src/App.jsx`:
```js
const API_BASE = "https://andy-website-i57z.onrender.com";
```
Then rebuild and redeploy.
